# ONE SHOT v4.4 · FIELD BASE

- Nuevo modo de trabajo: Captura Libre, Mixto y Seguimiento.
- Switch Historial cercano ON/OFF.
- Importación de Excel como Base de campo territorial.
- Activación/desactivación de bases sin borrar las capturas.
- Los antecedentes importados se comparan por proximidad GPS.
- Diferencia visual entre antecedente local y Base de campo.
- Resumen de jornada: capturas, permanece, modificada, retirada y lugares.
- La cámara funciona aunque no exista ninguna base cargada.

Nota: esta versión importa la información tabular y geográfica del Excel. Las fotos históricas ya guardadas en el dispositivo sí se muestran en comparación; para transportar grandes volúmenes de fotos históricas entre equipos se recomienda el paquete ZIP que se incorporará sobre esta base.
