# ONE SHOT v3.5.5 · EXCEL REPORT UX

## Rediseño del Excel
- `EVIDENCIAS`: hoja principal visual, limpia y filtrable.
- Fotos mucho más grandes y con proporción conservada.
- Solo se muestran en la entrega los datos que sirven para revisar la evidencia.
- `DATOS_TECNICOS`: hashes SHA-256, lente, resolución, fuente horaria, GPS desglosado y metadatos completos.
- `METADATOS`: información del reporte.
- El objetivo es que el Excel deje de verse como una exportación cruda de 36 columnas y se convierta en una entrega legible para auditoría.
