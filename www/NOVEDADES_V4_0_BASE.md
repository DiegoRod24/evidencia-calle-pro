# ONE SHOT 4.0 BASE

## Base territorial
- Nueva sección Lugares.
- Cada evidencia puede pertenecer a un punto físico estable.
- Migración no destructiva de evidencias anteriores: agrupa por cercanía muy corta (8 m) para construir una base inicial.
- Al capturar cerca de una evidencia anterior se muestra el flujo: Permanece / Modificada / Retirada / Nueva.
- Los procesos electorales siguen perteneciendo a cada evidencia; el lugar puede acumular historial de EG, ERM u otros procesos.

## Cámara
- Orientación inteligente basada en sensores: los iconos de cámara se adaptan a vertical/horizontal aunque la rotación del sistema esté bloqueada, cuando el navegador expone el sensor.
- El usuario puede desactivar esta función desde Configuración.

## Reportes
- Se conservan EVIDENCIAS, DATOS_TECNICOS y METADATOS.
- Se agregan LUGARES e HISTORIAL.

## Selección
- Estados seleccionados con animación y dock más moderno, manteniendo Todas/Ninguna/Acciones.
