# Modelo operativo
ANTES: cargar histórico -> crear campaña -> sectorizar -> asignar responsable.
DURANTE: generar ruta pendiente -> navegar -> verificar -> capturar -> marcar revisado.
DESPUÉS: exportar avance -> fusionar avances del equipo -> continuar en sectores pendientes -> generar Excel.

Estados territoriales: Pendiente, Revisado, Retirado, Nuevo, Cerrado.
La ruta no crea evidencias falsas. Un punto se considera revisado por acción del usuario o por una captura realizada cerca del punto planificado.
