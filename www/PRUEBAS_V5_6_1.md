# Pruebas ONE SHOT 5.6.1 · EASY INSTALL

1. Android Chrome: abrir por HTTPS y validar que **Instalar ONE SHOT** lance el diálogo nativo si `beforeinstallprompt` está disponible.
2. iPhone Safari: abrir guía y validar pasos Compartir → Añadir a pantalla de inicio.
3. Samsung Internet: validar guía específica.
4. Instalar y abrir desde el icono: el estado debe indicar **INSTALADA** y no volver a mostrar el aviso inicial.
5. Validar que evidencias y configuración anteriores permanecen intactas.
6. Probar Compartir instalación y Copiar enlace.
