# Pruebas v3.5

1. Publicar los archivos de v3.5 y abrir ONE SHOT.
2. Comprobar que no vuelve a aparecer el popup nativo del navegador para la misma versión.
3. Tomar una evidencia vertical y revisar:
   - hora con aire,
   - fecha/día al costado,
   - dirección separada,
   - GPS/hora servidor en línea secundaria,
   - Código de Foto al pie,
   - riel derecho continuo y legible.
4. Tomar una evidencia horizontal y repetir la revisión.
5. Entrar a Configuración > Aplicar marca a evidencias guardadas para regenerar fotos antiguas.
6. Abrir Ver evidencia y probar Guardar / Compartir / Verificar / Mapa / Ficha / Editar.
7. Abrir Editar con teclado visible y comprobar que Guardar cambios siga accesible.
8. Entrar a Mover controles y marca y verificar que el watermark pueda arrastrarse.
