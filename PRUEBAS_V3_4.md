# Pruebas recomendadas v3.4

1. Tomar una foto vertical y verificar:
   - logo superior izquierdo
   - hora grande abajo izquierda
   - fecha y día visibles
   - dirección completa
   - riel derecho de verificación
2. Tomar una foto horizontal y verificar la misma composición.
3. Cambiar el logo institucional en Configuración y probar de nuevo.
4. Probar tamaños de marca `Pequeña / Normal / Grande / Muy grande`.
5. Usar `Aplicar marca a evidencias guardadas` y revisar evidencias antiguas.
6. Exportar Excel para comprobar que la nueva marca se vea correctamente en miniaturas.
